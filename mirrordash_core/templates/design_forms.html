Configuration Form Controls

MirrorDash builds each module's settings form from its config_schema.json, picking the control by the property's type, format and name. Every field below is drawn by that same code from the JSON beside it: copy the JSON into your schema's "properties" to get the control. They come alive in the admin page (choices, uploads, Show). The admin page is in English only: write titles, descriptions and errors in English (a module's translations/ are for the mirror).
