Security Notice: Dashboard credentials are excluded from backups. Importing a backup will preserve your current active admin login password.
Storage Policy: Backups contain configuration files (`config.json`), local custom module code, and persistent databases (`data_dir`). Transient caches (`cache_dir`) are excluded.
WiFi Credentials: WiFi network passwords are intentionally excluded to keep backups free of sensitive network data. After restoring a backup, you may need to reconnect via the setup wizard if your mirror lost its network configuration.
